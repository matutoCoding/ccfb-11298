# 地毯绒面预览系统

浏览器里的地毯/挂毯绒面效果预览工具:TypeScript + WebGL2 自写着色器,无需后端,订单数据存在浏览器 localStorage。

## 运行

```bash
npm install
npm run dev      # 开发,默认 http://localhost:5178
npm run build    # 产出 dist/ 静态文件,任意静态服务器可托管
```

## 页面

| 页面 | 功能 |
|------|------|
| 订单 | 增删改、复制、单个导出/导入 JSON、全部备份,数据存浏览器 |
| 图案 | 导入 PNG → k-means 聚类 → 映射内置纱线色库(羊毛/真丝/化纤 48 色);点选色块可合并、替换 |
| 绒面工艺 | 俯视 2D 编辑:割绒/圈绒分区、绒高刷(高低绒浮雕)、恢复;蓝色=圈绒,暗色=低绒 |
| 三维预览 | 壳层绒毛渲染,房间场景,4 种灯光,顺毛刷/脚印笔刷直接画在毯面上,截图带订单参数,纱线用量清单(可导 CSV) |
| 设置 | 壳层层数、渲染分辨率、克重系数、损耗率、数据管理 |

## 渲染要点(为什么贴近看不穿帮)

- **壳层(shell)绒毛**:最多 64 层沿法线挤出,每层用密度噪声裁剪出毛簇截面
- **每像素抖动壳层阈值**:打散层与层的界线,消除"一层层薄片"感
- **MSAA + alpha-to-coverage**:毛簇边缘覆盖率抖动,转动视角不闪
- **噪声纹理 mipmap + 各向异性过滤**:远处自动平均,不 moiré
- **边缘裙边几何**:毯子侧面也是绒毛,不是切片
- 壳层数随相机距离自适应,近处加密、远处减少保帧率;真丝/羊毛/化纤三种高光模型(Kajiya-Kay 各向异性 + 丝的宽柔 sheen)
