# 绒面预览工作台 · Carpet Pile Studio

浏览器内的地毯/挂毯绒面实时预览系统。TypeScript + WebGL2 自研着色器，无 3D 引擎依赖，仅依赖 `gl-matrix` 做矩阵运算。

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5180
npm run build      # 生产构建到 dist/
npm run typecheck  # 严格类型检查
```

首次打开会自动生成一个带几何纹样和高低绒浮雕的演示订单。

## 五个页面

| 页面 | 功能 |
| --- | --- |
| 订单列表 | 新建/复制/删除/编辑（名称、客户、尺寸），localStorage 持久化，整库或单订单 JSON 导出/导入，导入自动重生成 ID 防冲突 |
| 图案编辑 | PNG 导入后按 CIE Lab 感知色差量化到纱线色板；显示各色占比；支持颜色合并（改写索引）、替换（改映射）、重命名、色板增删；量化图 R 通道存纱线索引 |
| 绒面工艺 | 7 种笔刷在工艺纹理上直接绘制：加高绒、压低绒、割绒、圈绒、顺毛刷（按拖动方向）、脚印压痕、擦除；绒高/密度/割圈比/顺逆毛色差/材质可调 |
| 三维预览 | 房间地面铺毯、轨道相机、5 种室内光（含傍晚低角度侧光）+ 方位/高度角微调、羊毛/丝/化纤切换、带订单参数的截图、纱线用量清单导出 |
| 设置 | 纤维倍率、实例上限、网格分段、阴影分辨率/开关、FPS 显示、自动保存与数据清空 |

## 渲染架构（针对"不穿帮、不闪、60fps"）

### 为什么近看不是一层层薄片

- **实例化扭曲丝带（instanced twisted ribbon）**：每根纤维是真实 3D 几何——3 段 12 顶点，截面随纤维参数扭转，割绒尖梢宽度收到 0（天然抗闪烁、无薄片感），圈绒为半圆拱。
- 纤维根部贴合底层位移网格的浮雕表面，不会悬空或穿插。
- 底层是按绒高图位移的网格，有限差分求法线，与纤维共同构成连续绒面。

### 为什么转动视角不闪

- 每根纤维的位置、倾斜、扭转、明暗全部由**确定性哈希种子**驱动，不依赖时间、相机或屏幕坐标（屏幕空间噪声已改为世界空间哈希）。
- 实测：同一视角逐帧像素一致；旋转后回到原角度，像素与旋转前完全一致。

### 光泽与绒感

- **Kajiya-Kay 各向异性高光**：沿纤维方向的长条柔光，三种材质参数不同——羊毛（低高光、强绒感）、丝（锐利+柔和双层高光）、化纤（锐亮）。
- 顺毛/逆毛色差由视角方向与绒向图的点积驱动；脚印压痕让纤维倒伏、变短、压暗。
- 平行光正交阴影贴图（PCF 3×3），纤维和底层都投射阴影，侧光下纤维投影可见。
- 颜色全程在线性空间计算，输出前转回 sRGB；数据纹理（纱线索引、LUT）使用线性格式避免被 GPU 自动解码污染。

### 60fps 与自适应

- 单次 instanced draw call 提交全部纤维；典型订单 7–15 万实例，独立显卡可满帧。
- **运行时自适应降载**：帧间隔超过 55ms 时自动逐档减少纤维、必要时关闭阴影，软件渲染/集显也能保持可交互；降载只影响当前会话，不改用户设置。
- 笔刷只更新纹理不重建实例，密度/尺寸变化才重建几何。

## 数据与估算说明

- 纱线用量基于经验体积密度与填充率系数估算（见 `src/core/usage.ts`），量产前请用真实打样数据校准顶部常量。
- 所有数据存浏览器 localStorage；订单内图案/工艺图以 PNG dataURL 内嵌，导出的 JSON 可直接在另一台机器导入。
